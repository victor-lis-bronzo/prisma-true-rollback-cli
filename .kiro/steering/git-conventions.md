# Git & Commit Conventions

## Never self-identify in commits

- Do NOT identify yourself (the AI assistant / Kiro) as the author or co-author of any commit.
- Do NOT add `Co-authored-by:` trailers referencing the assistant, agent, or any bot identity.
- Do NOT include phrases such as "Generated by", "Created with", "Co-authored-by Kiro", or similar attribution in commit messages, commit bodies, or PR descriptions.
- Commit messages should describe only the change itself, with no mention of the tooling or assistant that produced it.
